## What's Changed

### ✨ New Features
- Redesigned dialog that brings live status, manual controls, firmware updates, and one-time activation together in one place
- Wired and Wireless (ESP-NOW) modes with a single toggle
- Pair and unpair the wireless dust boot directly from the panel
- Marker-based retract/expand insertion for more reliable dust boot moves during tool changes
- Travel calibration plus tap-and-hold wireless jogging

### 🔧 Improvements
- Live position readout in mm or inch, with travel clamped to your configured limits
- Clearer three-state connection status
- Taller code editor and a tidier layout after firmware updates

### 🐛 Bug Fixes
- Fixed the Expand control and native-USB device detection
- Firmware downloads now go through the server to avoid browser CORS errors
